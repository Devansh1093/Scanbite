# ScanBite

ScanBite is a mobile application for scanning food products and viewing their nutritional information.

## Features

- Barcode scanning
- Nutrition information and score
-  Product search
-  History of past products

## Tech Stack

### Frontend
- React Native
- JavaScript
 

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### APIs
- Open Food Facts API

### Deployment
- Render
- Expo Application Services (EAS)
